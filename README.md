Название проекта

# Stellar Burgers Automation Tests

Описание

Praktikum Project
Этот проект представляет собой тестовое приложение, разработанное с использованием Maven. Проект включает настройку для выполнения модульных тестов с помощью JUnit и Mockito, а также интеграцию с JaCoCo для анализа покрытия кода тестами.

Технологии и зависимости
Язык программирования
Java 11 : Проект использует Java версии 11, как указано в свойствах maven.compiler.source и maven.compiler.target.

Зависимости
Проект использует следующие библиотеки:

JUnit 4.13.1 Библиотека для написания и выполнения модульных тестов.
Mockito 3.12.4 Библиотека для создания мок-объектов и тестирования взаимодействий между компонентами.

Плагины
Проект использует плагин JaCoCo для анализа покрытия кода тестами.

JaCoCo Maven Plugin 0.8.7 Генерация отчетов о покрытии кода тестами.
Настройка:
Цель prepare-agent : Выполняется на фазе initialize для подготовки агента JaCoCo.
Цель report : Выполняется на фазе verify для генерации HTML-отчета о покрытии.

Команды Maven
Сборка проекта

mvn clean install

Эта команда выполняет сборку проекта, включая запуск тестов и генерацию отчетов JaCoCo.

Запуск тестов

mvn test

Эта команда запускает все тесты, определенные в проекте.

Генерация отчета JaCoCo

mvn verify

После выполнения этой команды отчет о покрытии будет доступен в папке:

target/site/jacoco/index.html

Отчет о покрытии кода
После выполнения команды mvn verify, JaCoCo создает HTML-отчет о покрытии кода тестами. Отчет можно открыть в браузере:

open target/site/jacoco/index.html
